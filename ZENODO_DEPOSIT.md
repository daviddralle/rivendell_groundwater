# Manuscript archive v0.3.0

Concept DOI: https://doi.org/10.5281/zenodo.20361535

This release uses the manuscript title “From Storms to Low Flows: Storage and Drainage in a Bedrock Hillslope Aquifer.” The release contains the three executed notebooks, the interannual recession script, their shared processing modules and tests, the selected frozen inputs, derived numerical tables, and figures. Earlier exploratory analyses remain in the working checkout and are excluded from this release.

The repository's existing Zenodo release webhook creates a new version when a GitHub release is published. Verify the resulting archive contents and version DOI before updating the manuscript citation. The full manuscript is not published as part of the data/code release.
