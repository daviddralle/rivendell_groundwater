# Rivendell Weathered Bedrock Groundwater Analysis

This repository contains the analysis notebooks, datasets, and generated figure outputs that accompany the manuscript:

**Weathered Bedrock Controls Stormflow, Baseflow, and Recharge While Limiting Hydrologic Memory**

The archive is organized to reproduce the paper analyses from a compact set of inputs.

## Contents

| Path | Description |
| --- | --- |
| `01_site_characterization.ipynb` | Builds daily precipitation summaries, the wet/dry water-year comparison, and the annual low-flow sensitivity figure. |
| `02_bedrock_vadose_storage_capacity.ipynb` | Documents the neutron-probe rock-moisture workflow and generates the bedrock vadose-zone storage-capacity figure and table. |
| `03_groundwater_streamflow_analysis.ipynb` | Generates the groundwater-storage, streamflow-yield, recession-event, weekly drainable-porosity, and peak-groundwater sensitivity analyses. |
| `Data/` | Input datasets required by the notebooks. |
| `Plots/` | Manuscript figure outputs generated by the notebooks. |
| `.zenodo.json` | Zenodo metadata prepared for DOI deposition. |
| `CITATION.cff` | Citation metadata for GitHub and archival services. |
| `requirements.txt`, `environment.yml` | Python environment specifications. |

## Data Inventory

| File | Role in analysis |
| --- | --- |
| `Data/angelo_precip_5m.csv` | Five-minute Meadow weather-station precipitation used to generate daily precipitation. |
| `Data/meadow_precip_daily.csv` | Daily Meadow precipitation used in the wet/dry water-year comparison. |
| `Data/prism_ppt.csv` | PRISM precipitation used for water-year precipitation and interannual sensitivity analyses. |
| `Data/elder_creek_clean.csv` | Daily Elder Creek runoff record used for low-flow and storage-discharge analyses. |
| `Data/groundwater_hourly_resampled.csv` | Hourly groundwater records used for event, seasonal, and interannual groundwater analyses. |
| `Data/storage_ts.csv` | Processed neutron-probe bedrock vadose-zone storage time series. |
| `Data/rivendell_theta_depth_timeseries.csv` | Exported depth-resolved neutron-probe moisture observations. |
| `Data/wells.gpkg` | Full monitoring-well point layer used for groundwater-storage geometry and stream-distance calculations. |
| `Data/rivendell_wells.gpkg` | Curated Rivendell well layer with storage-capacity, groundwater-response, and hillslope-position attributes used in exploratory/profile plots. This file is not interchangeable with `Data/wells.gpkg`. |
| `Data/elder.tif` | Digital elevation raster used to estimate well elevations and stream-to-ridge geometry. |
| `Data/weekly_inferred_porosity.csv` | Derived weekly drainable-porosity estimates generated by the groundwater analysis. |

## Reproducing the Analyses

Create the Python environment:

```bash
conda env create -f environment.yml
conda activate rivendell-groundwater
```

or, with `pip`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run the notebooks from the repository root in this order:

1. `01_site_characterization.ipynb`
2. `02_bedrock_vadose_storage_capacity.ipynb`
3. `03_groundwater_streamflow_analysis.ipynb`

The notebooks write manuscript figures to `Plots/` and render the figures inline when run. The included `Plots/` files are the current figure outputs used in the draft manuscript.

## Notes on Raw and Processed Data

The neutron-probe notebook documents the workflow used to convert depth-resolved moisture observations into bedrock vadose-zone storage. The processed storage products used by the manuscript are included in `Data/storage_ts.csv` and `Data/rivendell_theta_depth_timeseries.csv`, so the downstream figures and storage-capacity analysis can be reproduced from archived data.
